📌 Overview

This project analyzes Blinkit sales data using Microsoft Excel to uncover insights related to sales performance, customer behavior, and product trends. An interactive dashboard is built using pivot tables, charts, and slicers to enable dynamic data exploration.

📊 Key Features
Interactive dashboard with slicers
Dynamic filtering by category, outlet, and location
KPI tracking for sales performance
Visual insights using charts and graphs
🧠 Business Problems Solved

🔹 Sales Analysis
Total Sales and Average Sales
Sales by Product Category
Outlet-wise Sales Performance

🔹 Product Insights
Top Selling Products
Category-wise Demand
Product Performance Comparison

🔹 Outlet Analysis
Sales by Outlet Size (Small/Medium/Large)
Sales by Outlet Location Tier
Outlet Establishment Trend

⚙️ Tools & Techniques Used
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers (for interactivity)
Data Cleaning & Transformation
KPI Metrics

📈 Key KPIs
Total Sales
Average Sales
Number of Items Sold
Average Rating

🎯 Project Objective

To build an interactive Excel dashboard that provides meaningful insights into Blinkit’s sales data and supports data-driven decision making.

🚀 How to Use
Open the Excel file

Analyze trends using charts and KPIs
Explore different business scenarios
